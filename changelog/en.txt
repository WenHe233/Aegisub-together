Version 4.2 ---
https://github.com/croni1012/Aegisub/releases/download/v4.2/aegisub-v4.2.zip
- "open/video/recent" command
- "Open MKV" option in the file menu, which opens the mkv as subtitles and as video at once
The rest of the update revolved around the visual tools:
- Cross
    - distance measurement by holding the mouse button
- Drag (pos/move)
    - laggy movement fixed, it is lightning fast now
    - a new option was added at the bottom for centring inside a given rectangle
- Vector clip
    - you can switch between shapes in the first mode
    - delete the active shape with DELETE
    - BRUSH mode (NEW!): add to or take away from the selected area with a brush
    - DELETE mode: with several points selected, all of them can be deleted
    - PIPETTE mode (NEW!): enters a separate section where shapes can be created inside a given range and finally accepted, which adds them to the existing clip
        - 4 modes: colour range add/subtract and brush add/subtract
        - tolerance adjustment for the colour range
        - offset in pixels (negative values are allowed too)
        - AI recognition
- Mask editing (NEW!)
    - an existing mask can be edited directly, as if it were a vector clip
    - it received every vector clip mode, the new ones included
- Masking (NEW!)
    - masks can be created with a rectangle, with points, with a brush or freehand
    - on accepting the created mask it takes a colour from its edge automatically and creates the line
    - PIPETTE mode is available here as well
    - AI text removal / custom prompt for the selected area
- Shape drawing (NEW!)
    - predefined shapes can be created, which are made with blur and colour adjustment after accepting them
    - you can switch between hollow and filled shapes
    - holding ALT forces a regular shape (a square or a circle, for example)
    - line thickness can be set as well
    - corner rounding can be set as well
    - freehand drawing is possible too (for circling something, for example)

Version 3.6 ---
