这是 Aegisub Together 的早期测试版本。本版本升级到协作协议 v2，与 v0.0.3 及更早版本不兼容；客户端与服务端必须同时升级，不能混用不同协议版本。

本次更新重点：

- 协议 v2 引入原子多行锁集合。选择变化会一次请求完整行集合，任何一行冲突都会拒绝整组请求并释放旧锁，不会出现部分授予。
- 恢复多行选择时的原版编辑语义：文本与字幕字段可应用到全部选中行，格式标签仍只作用于活动行光标位置。
- 修复多选后单击其中一行时编辑栏内容与活动行不一致，以及向上、向下拖选时活动行没有跟随最后经过行的问题。
- 修复协作模式下 Ctrl+H 和菜单无法可靠打开查找替换窗口的问题；选中范围替换会检查完整锁集合，全局替换通过维护模式原子执行。
- 锁定状态改为整行显示：自己的锁为浅绿色、其他成员的锁为浅红色；选中行保留原版底色并叠加边框和左侧色带，无锁房间的远端活动行显示浅蓝色虚线边框。
- 字幕网格偏好设置新增三种协作状态颜色；悬停远端锁定行会显示持有者昵称，活动行被他人锁定时会在状态栏提示。
- 退出或主动断开时继续发送 `leave_room`，服务端立即释放昵称、完整锁集合、presence、恢复会话和维护租约。
- 补齐 v0.0.4 新增协作界面的简体中文翻译，并将 Windows CI 与发布流程统一固定为 Meson 1.11.2。

升级服务端前请先备份 SQLite 数据库。协议升级不改变数据库结构，但旧客户端会被明确拒绝。公网仍应使用 `wss://`；`ws://` 只适合本机、隔离开发环境或可信局域网。部署前请阅读[协作服务端部署指南](https://github.com/WenHe233/Aegisub-together/blob/v0.0.4/docs/collaboration-deployment.md)。
