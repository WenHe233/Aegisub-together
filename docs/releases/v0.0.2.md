这是 Aegisub Together 的早期测试版本，主要用于验证在线协作、部署和自动发布流程，尚不建议用于无法承受数据损失的正式字幕项目。

本次更新重点：

- Windows 客户端现在同时支持 `wss://` 和 `ws://`。公网仍应使用 WSS；首次连接每个明文 WS 地址时会显示风险提示。
- 协作服务端部署指南、服务端 README 和协议 v1 README 已改为中文，并补充可信局域网 WS 部署说明。
- 修复 Windows 便携包 Action 中 zlib、Boost 和 uchardet 上游下载地址失效或哈希不匹配的问题。
- 推送语义化版本标签后会自动生成 Windows 便携包、Linux amd64/arm64 服务端、校验和、SBOM 和 GitHub Release。

部署前请阅读[协作服务端部署指南](https://github.com/WenHe233/Aegisub-together/blob/v0.0.2/docs/collaboration-deployment.md)。
